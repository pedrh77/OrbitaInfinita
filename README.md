# Órbita Infinita

Protótipo mobile-first de jogo casual infinito feito em Canvas 2D.

## Como jogar

Abra `dist/index.html` por um servidor local. Segure a tela para carregar o impulso e solte para lançar a nave ao próximo planeta.

## Integrações preparadas

- `window.OrbitaAds.showRewarded()` pode ser substituído pelo SDK de anúncios.
- `window.OrbitaMonetization.purchase(productId)` pode ser substituído pela loja nativa.
- O progresso é salvo localmente no navegador.
